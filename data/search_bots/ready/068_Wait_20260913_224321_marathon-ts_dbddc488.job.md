Review software source code for quality, readability, consistency, and adherence to client standards.
Analyze pull requests (PRs) and provide detailed feedback in accordance with established review guidelines.
Ensure code changes comply with documented coding standards, security requirements, and development best practices.
Document findings clearly and professionally.
Follow established workflows and approval processes for code reviews.
Maintain strict confidentiality of proprietary source code and client information.
Work independently while meeting project deadlines.
Collaborate remotely with project stakeholders as needed.
Adhere to all client security protocols throughout the engagement.
