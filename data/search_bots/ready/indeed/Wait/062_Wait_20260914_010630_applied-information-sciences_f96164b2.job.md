Project Summary

AIS is seeking an Integration and Automation Engineer to design and deliver resilient integrations and automation services that connect modern applications to enterprise systems, flat-file exchanges, and external partners for a federal customer.

Key Responsibilities

Design secure API, file-transfer, event, and batch-integration patterns for Power Platform, Azure, SharePoint, and external systems.

Build and support Azure Functions, Logic Apps, custom connectors, data transformations, and error-handling workflows.

Implement flat-file generation, validation, partitioning, retry, exception-management, and audit requirements.

Collaborate with application teams to replace vulnerable legacy Java transfer components with secure, maintainable services.

Develop automated tests, monitoring, alerts, and support runbooks for integrations.

Participate in security reviews covering authentication, encryption, secrets management, and least-privilege access.

Required For This Opportunity

5+ years of application integration, automation, or backend engineering experience.

Hands-on experience with Azure Functions, Logic Apps, APIs, JSON, file processing, and secure authentication patterns.

Experience with message handling, error recovery, observability, and production troubleshooting.

Proficiency in at least one modern programming or scripting language such as Java, C#, Python, or JavaScript.

Strong understanding of data security and integration architecture.

Nice to Have Skills

Power Platform custom connector experience.

Azure Government or B2B/external-partner integration experience.

Experience refactoring legacy Java applications.
