Job Description

Senior Business Intelligence & Reporting Analyst, RBC Capital Markets, LLC, Jersey City, NJ:

Manage and govern enterprise Tableau platforms for Global Markets analytics, overseeing BI developers and enforcing SDLC protocols. Deliver secure, high-performance reporting by architecting advanced Tableau dashboards and administering Tableau Server in high-availability environments. Lead data engineering efforts with SQL Server, optimizing schemas and queries, and automate data refresh and report distribution using Control-M and Python. Integrate data from multiple sources including Snowflake, Databricks, Cloudera Impala, and relational databases. Translate business requirements into robust data models and documentation, supervise two BI Developers, and ensure compliance with governance standards.

Telecommuting permitted up to 1 day per week.

#LI-DNI

MINIMUM REQUIREMENTS:

Must have a Bachelor’s degree or foreign equivalent in Computer Science, Engineering, or a related field and 5 years of progressive, post-baccalaureate related work experience.

Must have 3 years of experience in each of the following:

Administering Tableau Server in High Availability (HA), clustered enterprise environments, including Tableau Service Manager (TSM) and Tabcmd, content governance.
Security Assertion Markup Language (SAML), Active Directory (AD) integration, row level security, subscriptions, scheduling, backup, restore, migrations, and upgrade planning.
Advanced development in Tableau Desktop including Level of Detail (LOD), table calculations, parameter actions, complex joins, blends, extract optimization and performance recording.
Programming in SQL Server and T SQL, including indexing, partitioning, query plan optimization, stored procedures, functions, and security models including schemas and roles.
Python for BI automation, including production use of the Tableau REST API and Tableau Server Client (auth, publish, permissions, schedules, and metadata).
Building and orchestrating Control M jobs for data refresh and distribution.
Snowflake, Databricks and Delta Lake, and Cloudera Impala and cloud based analytics tools including Sigma, Alteryx and Tableau on cloud.
Hands on Open Database Connectivity and Java Database Connectivity configurations and performance tuning.
Supporting Global Markets, Capital Markets, Securitized Products functions, including product data structures, trade lifecycle, pricing, exposure calculations, and control, reporting workflows.

Must have 2 years of experience in each of the following:

Supervising BI developers through task allocation, code reviews, mentoring, and performance feedback.
Enterprise SDLC in regulated financial institutions: change management, segregation of duties, release controls, evidence capture for audit including – System Development Life Cycle (SOX), SOC2.
Extracting and securing large data volumes for Business Intelligence (full and incremental), row level security, and performance optimization for high concurrency user bases.
