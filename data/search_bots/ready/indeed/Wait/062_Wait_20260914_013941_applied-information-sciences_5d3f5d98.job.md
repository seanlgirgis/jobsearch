Project Summary

AIS is seeking an Azure Data / Databricks Engineer to build secure, reliable Azure data pipelines and analytics foundations that modernize legacy Oracle workloads and enable governed reporting and analytics for a federal customer.

Key Responsibilities

Design and implement ingestion, transformation, and data-quality pipelines using ADLS Gen2, Azure Databricks, and approved orchestration services.

Migrate and modernize Oracle data workloads while preserving lineage, reconciliation, security, and performance requirements.

Develop medallion-style data models, notebooks, jobs, monitoring, and operational support practices.

Collaborate with business and BI teams on curated data sets, Power BI integration, and data-consumption standards.

Implement secure identity, network, storage, and access patterns appropriate for Azure Government environments.

Document pipeline operations, data quality checks, recovery procedures, and support handoff materials.

Required For This Opportunity

5+ years in data engineering, ETL/ELT, or analytics-platform delivery.

Hands-on experience with Azure Databricks, ADLS Gen2, SQL, Python, and data-pipeline orchestration.

Experience migrating relational or Oracle data workloads to cloud data platforms.

Knowledge of data modeling, data quality, reconciliation, monitoring, and performance optimization.

Strong problem-solving and stakeholder-communication skills.

Nice to Have Skills

Azure Government or regulated data-platform experience.

Power BI, Unity Catalog, Delta Lake, or Azure Data Factory experience.

Databricks or Azure Data Engineer certification.
