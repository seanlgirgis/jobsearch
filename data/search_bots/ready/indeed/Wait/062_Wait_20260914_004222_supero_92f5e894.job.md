Job Overview
We are seeking a skilled Cloud / Platform Engineer with expertise in Kubernetes, GCP, and AWS to join our dynamic team. This role involves designing, implementing, and managing cloud infrastructure and services to support scalable and reliable applications. The ideal candidate will have a strong background in cloud computing, DevOps automation, and infrastructure management, with a focus on public cloud platforms. You will play a key role in optimizing cloud environments, automating deployment processes, and ensuring efficient cloud operations to meet organizational needs.

Duties

Manage and optimize cloud infrastructure across multiple public cloud platforms such as AWS and GCP.
Develop and maintain scalable cloud services to support application deployment and operations.
Implement Infrastructure as Code (IaC) using scripting languages and tools to automate provisioning and configuration of resources.
Design and deploy containerized applications using Kubernetes, ensuring high availability and security.
Automate DevOps workflows to streamline deployment pipelines, monitoring, and incident response.
Oversee cloud management tasks including resource allocation, cost optimization, and security compliance.
Maintain Linux-based environments supporting cloud infrastructure components.
Collaborate with development teams to integrate cloud solutions into application architectures.
Monitor system performance, troubleshoot issues, and implement improvements for cloud environments.

Experience

Proven experience in managing cloud infrastructure on AWS and Google Cloud Platform (GCP).
Strong knowledge of Kubernetes orchestration for containerized applications.
Hands-on experience with scripting languages such as Bash, Python, or similar for automation tasks.
Expertise in Infrastructure as Code (IaC) tools like Terraform or CloudFormation.
Familiarity with DevOps practices including CI/CD pipelines, automation tools, and monitoring solutions.
Experience working with Linux operating systems in a cloud environment.
Ability to troubleshoot complex issues related to cloud services, networking, and security.
Prior experience in designing scalable, reliable, and secure cloud architectures is highly desirable.

Join us to be part of an innovative team focused on leveraging cutting-edge cloud technologies to drive business success!
