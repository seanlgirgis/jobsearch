# Scheduling: Airflow, Autosys, Control-M

## Safe Comparison
- Airflow: Code-first DAG orchestration, Python ecosystem, strong visibility.
- Autosys: Enterprise scheduler, calendar/dependency driven batch control.
- Control-M: Enterprise workload automation with strong operational tooling.

## Core Concepts
- DAG: Directed graph of task dependencies.
- Dependency: Upstream must complete before downstream starts.
- Retry: Automatic rerun after failure with policy.
- SLA: Expected completion window.
- Alert: Notification on failure/SLA breach.
- Backfill: Run for historical periods.
- Rerun: Re-execute failed or corrected slice.
- Job calendar: Run schedule tied to business/holiday rules.
- Upstream/downstream: producer/consumer job relation.
