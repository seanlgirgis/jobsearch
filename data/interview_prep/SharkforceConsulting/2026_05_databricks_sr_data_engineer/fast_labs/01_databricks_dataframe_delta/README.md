# Lab 01: Databricks DataFrame to Delta Table

## Purpose

This lab gives Sean a small hands-on Databricks exercise for the Sharkforce Sr. Data Engineer interview.

It practices the basic Databricks data engineering flow:

```text
sample records
-> Spark DataFrame
-> simple transformation
-> quality-friendly normalized columns
-> Delta table
-> SQL query
```

## Outcome

After this lab, Sean can explain notebook workflow, Spark DataFrame transformation, Delta write, and SQL validation in a clear interview-ready way.
