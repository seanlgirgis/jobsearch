Summary
Qualitest is seeking a Performance Test Lead / Mid-Level Performance Test Engineer with strong expertise in performance testing, Apache JMeter, and Azure Load Testing. The candidate will be responsible for designing and executing performance test strategies for large-scale enterprise applications, ensuring scalability, reliability, and system stability under varying load conditions.

Key Responsibilities

Design, develop, and execute performance test strategies and test plans
Create, maintain, and execute Apache JMeter scripts
Perform load, stress, spike, and endurance testing
Execute performance tests using Azure Load Testing
Simulate real-world load scenarios, including peak and high-traffic conditions
Analyze performance metrics: response time, throughput, CPU, memory, and network utilization
Identify and troubleshoot performance bottlenecks across application, database, middleware, and infrastructure layers
Generate performance reports and dashboards
Collaborate with development, DevOps, and infrastructure teams
Integrate performance testing into CI/CD pipelines
Support performance validation for enterprise releases
Participate in capacity planning and performance benchmarking
Maintain performance testing documentation and frameworks
Required Skills and Qualifications

4 7 years of experience in software testing, with at least 3 years in performance testing
Strong hands-on experience with Apache JMeter
Test plan design
Script development and parameterization
Correlation and debugging
Distributed testing
Experience with Azure Load Testing
Experience using PowerShell for Azure interactions
Strong data analysis skills using Microsoft Excel (including Macros)
Experience with APM tools (Dynatrace, AppDynamics, Splunk)
Knowledge of HTTP, REST APIs, and Web Services
