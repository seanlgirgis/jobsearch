Summary
Genesis10 is currently seeking a Performance Tester - Remote position with a Major Financial Services Company located remotely or in Boston, New York, Philadelphia, Cleveland, Richmond, Atlanta, Chicago, St. Louis, Minneapolis, Kansas City, Dallas, or San Francisco. This is a 12+ month contract opportunity.

Pay range: $65.00 - $75.00 per hour

Description:
We are seeking leaders who will help define the vision, strategy, values, and priorities that enable our client to achieve its mission. This role is responsible for executing end-to-end performance testing, including requirements gathering, test planning, scripting, execution, and analysis, while partnering closely with development, architecture, infrastructure, and engineering teams. The ideal candidate brings a strategic, action-oriented mindset, with strong intellectual curiosity, agility, accountability, and a passion for driving innovation through experimentation.

Responsibilities:
Execute end-to-end performance testing, including requirements gathering, test planning, scripting, execution, analysis, and results reporting to stakeholders.
Evaluate system under test (SUT) communication protocols to determine appropriate scripting approaches
Partner with product development, implementation, architecture, infrastructure, and engineering teams to define success criteria and evaluation methodologies
Design and implement load test scenarios, including load, stress, volume, and failover testing
Collaborate across dependent teams to ensure the successful execution of performance test cycles
Work with security teams and test engineers to integrate security requirements into the overall testing strategy and pipeline
Perform manual testing to validate vulnerabilities
Monitor server utilization during test execution
Participate in code reviews for performance test scenarios and develop/maintain test data
Evaluate non-functional requirements to establish acceptance criteria
Analyze production logs to determine target and peak, load models
Upload performance test scenarios and related artifacts to Subversion and/or other management tools as required
Coordinate with configuration management to schedule test execution and support automated software deployment
Maintain performance test scripts and scenarios
Conduct API performance testing and integrate results into CI pipelines
Monitor system-level metrics during test execution
Develop and deliver performance test reports and analyze results
Gather and correlate front-end and back-end performance data to produce comprehensive reporting
Support the implementation and maintenance of performance testing tools
Utilize CI tools to support continuous integration for performance and load testing

Requirements:
Bachelor's degree in Software Engineering, Computer Science, Information Technology, Business Administration, or a related field, or equivalent experience
10+ years of experience in performance testing, including at least 3 years on large-scale projects with minimal supervision
4-6 years of hands-on experience in performance testing, with strong knowledge of methodologies, concepts, and best practices
4-6 years of experience developing and executing performance test scripts using tools such as LoadRunner, Performance Center, or JMeter
Advanced programming knowledge in Python, JavaScript, Java, or Visual Basic
Experience developing performance testing scripts for MQ, Java Cloud, and AWS-based applications
Proven ability to execute end-to-end performance testing across requirements, planning, scripting, execution, and analysis
Experience designing performance tests for load, stress, spike, scalability, and volume testing
Strong experience applying best practices in load generation, bottleneck analysis, modeling tools, and statistical analysis
Experience using server monitoring tools such as Dynatrace, Splunk, or similar
Strong analytical skills with the ability to interpret and present performance test results to product and technical teams
Proficiency with development tools such as IntelliJ, Eclipse, and source control systems like Git or Subversion
Experience with advanced programming concepts (e.g., threading, exceptions, I/O, memory management) within the Java ecosystem
