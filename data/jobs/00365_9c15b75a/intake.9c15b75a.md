Summary
This role outlines the need for a highly motivated and result oriented change champion who will act as a Test Lead Engineer that will be embedded into one or more technology programs/peaks from the Testing Enablement team. This individual must ensure best practices and processes are adapted to the project team’s specific needs and help identify areas to help build testability in from the start. Another key aspect of this role is to combine/identify opportunities for hands on testing, Test Automation and Performance Engineering to ensure that projects are delivered with better reliability, performance and user acceptance. 

Responsibilities: 
• This individual must maintain and promote enterprise-wide testing standards, tools and methodologies. 
• Provides training and mentorship to the testers in the application teams and help implement the best practices provided by the Testing Enablement Team. 
• The Test Lead will function as a partner between the Tower Lead and the Program Manager to provide detailed and daily updates on testing status, artifacts and reports. 
• Must be able to work closely with the developers and product managers/owners to help with identifying areas of improvement for Virtualization, Test Automation and Performance Engineering on a regular on-going basis. 
• Identify Test Automation opportunities and enable automation team to develop and maintain the automation test suite. 
• Must maintain Performance Testing artifacts and should be involved with Performance Metrics evaluation along with the Performance Testing team. This individual must be able to provide input to the Non Functional Requirement (NFR). 
• Must work closely with the Testing Enablement Function Lead to identify and foster creation and usage of virtualized services for various phases of testing and have them ready prior to testing cycles. Early identification of various opportunities is key. 
• Take ownership of developing the Testing Strategy and update as the strategy evolves. 
• Ensure that the Testing Strategy will include the updated Test Plan, Environment Strategy, Code management strategy and testing utilization. 
• Manage resource allocation and utilization throughout the project. Identify ramp up and ramp down needs based on project needs. 
• Identify work stream leads and manage work allocations on each work stream lead according to project requirements. 
• Oversee environment requirements for testing phases and work closely with Environment Manager and test leads to close the gaps and get all environment and infrastructure identified and ready prior to testing. 
• Work closely with the Defect Triage team to ensure Defect Triage and Requirement Traceability is coordinated with prioritizing defect fixes with Release Management. 
• Assess and report on project testing health metrics by taking inputs from Functional Lead, Development lead, application team lead etc. Report on the Testing Metrics on a regular frequency to ensure clear visibility to leadership on progress. 
• Must be a fast learner to possess deep understanding of the project team’s application architecture, priorities and be able to provide quick feedback for improvement at the same time balancing team priorities with enterprise governance standards. 
• Stay current with new test technologies and recommend the implementation of those to program managers / Tower Lead and analyze how that can improve the current ways of working. 
• Help each team identify opportunities to shift to a Test Driven Development model and enable/foster maturity to shift left. 
• Must be able to show a tangible result with improved defect identification, test automation coverage and improved performance test metrics. 
• Work closely with other vendors that are part of the testing team. 
 
Required Skills & Experience: 
• Strong knowledge of Testing frameworks and tools and proficiency in one programming scripting language. Knowledge in Type Script, Java, Python a plus. 
• Must posses very strong project management skills in order to complete all project deliverables 
on time.  
• Familiarity with Agile and Waterfall methodologies and also well versed with the CI/CD pipelines. Knowledge on GitLab CI a plus. 
• Strong knowledge on test automation and Performance Testing tools is a must. Tools like Playwright, Junit, TestNG, Test Complete, NeoLoad/JMeter a must. 
• Must be able to work in a hybrid model with a set number of days from the office depending on the team’s schedule. Also flexible to move to a full time office schedule depending on project needs. 
• Must be flexible in order to work overtime if at all required to support team activities.
