About the job
Our client in Addison, TX, is seeking a Senior Python Platform Engineer to design and build resilient, cloud-native backend systems that support critical enterprise operations. This is a hands-on role focused on creating scalable, self-healing platforms that perform reliably in production environments.

You’ll modernize backend services, replace fragile automation with distributed systems, and build infrastructure centered on scalability, observability, fault tolerance, and maintainability.

This is a 4-month, contract-to-hire opportunity working fully on-site in Addison, TX.



CONTRACT PAY: Up to $87/hour depending on candidates experience, etc.

WHAT YOU’LL DO:

Design and develop scalable Python backend services, APIs, and automation platforms
Modernize legacy Python processes into maintainable cloud-native architectures
Build distributed systems capable of handling large-file processing and long-running workloads
Implement resiliency patterns including retry logic, checkpointing, recovery workflows, and fault isolation
Engineer self-healing systems that can recover from network interruptions, infrastructure instability, and container restarts
Deploy and manage containerized applications using Docker and Kubernetes (AKS preferred)
Develop workflow orchestration solutions using Apache Airflow or similar platforms
Build and maintain CI/CD pipelines and deployment automation
Establish monitoring, logging, alerting, and observability standards across production environments


WHAT YOU’LL BRING:

10+ years of software engineering experience with strong expertise in Python 3.x backend development
Proven experience building and operating scalable production systems
Strong understanding of distributed systems, resiliency engineering, and platform reliability
Hands-on experience with: Python, Docker, Kubernetes / AKS, Azure cloud services, Apache Airflow, Linux, REST APIs, SQL databases, Git / GitLab, & CI/CD pipelines
Experience with any of the following is a strong plus: Azure Container Apps, Azure Storage Accounts, Azure Service Bus, Azure Key Vault, Azure Monitor / Application Insights, Redis, Solr, JavaScript, Java, & C/C++
